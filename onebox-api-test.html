POST /oauth/token

Exchange client credentials for an access token. The token is a JWT valid for 43 200 s (12 h) and must be sent as Authorization: Bearer <token> on every subsequent call.

Request
POST https://api.oneboxtds.net/oauth/token

Content-Type: application/x-www-form-urlencoded

# body (x-www-form-urlencoded)
grant_type=client_credentials
channel_id=2287
client_id=seller-channel-client
client_secret=••••••••••••••••••••••••••••••••
Response 200 OK
{
  "access_token": "<REDACTED — JWT, 12h expiry>",
  "token_type": "bearer",
  "expires_in": 43200,
  "scope": "api-channels-all api-distribution-all
           api-catalog-all api-external-all
           api-gateway api-customers-mgmt-all
           api-orders-mgmt-all"
}

GET /catalog-api/v1/sessions

Returns the full list of sessions (matches) available on the configured channel, with venue, event metadata and multilingual texts. In production this is the source of truth for the «¡Avísame!» match dropdown.

GET https://api.oneboxtds.net/catalog-api/v1/sessions

GET /catalog-api/v1/sessions/{sessionId}/availability

Returns seat availability for a single session, broken down by price type (which maps to the stadium grada: PISTA, VIP, …). This is what powers the «notify me when my grada opens» logic.
